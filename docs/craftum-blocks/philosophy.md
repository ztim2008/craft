# Философия · Craftum Blocks

## Проблема

Craftum даёт ~170 штатных блоков. Дизайнеры и студии хотят **свои** макеты — но официальной библиотеки сторонних блоков нет. Сейчас блоки копируют вручную или живут в головах команды.

## Решение

**ANNEXX-модель для Craftum:**

1. Автор собирает блок **внутри Craftum** (привычный редактор, штатные «Контент / Дизайн»).
2. Публикует snapshot в **наш каталог** (один ключ, одна кнопка).
3. Любой с расширением вставляет блок в свой проект за один клик.

Мы **не** становимся конструктором и **не** подменяем Craftum. Мы — слой «мои блоки поверх их редактора».

## Главный принцип

> Кастомный блок = **JSON-снимок дерева Craftum** (`craftumBlock`), а не HTML и не React-компонент.

После вставки текст, кнопки и картинки правятся **штатными** средствами Craftum — потому что внутри остаются узлы `data-type` (text, button, image…).

## Что делаем

- Расширение MV3: панель «Мои блоки» при открытии «+» в редакторе.
- Облачный каталог на `craft.nordic-builder.ru`.
- Режимы вставки:
  - **snapshot** — полный кастомный блок (основной путь);
  - **cover / hero / design** — обёртки над штатным UI Craftum (legacy MVP).
- Публикация с Craftum → сервер (ключ в модалке расширения).

## Что не делаем

| Не делаем | Почему |
|-----------|--------|
| Пункт в библиотеке «170 блоков» Craftum | Только партнёрство с Craftum |
| Свой renderer / HTML-вставка | Ломает редактирование и пресеты |
| Привязка к Craft-мигратору | Другой продукт, другой пользователь |
| Playwright в проде расширения | Только разведка и CI-тесты |
| Трогать site 954959 | Прод-клиент пользователя |

## Целевой пользователь

1. **Автор блоков** — веб-дизайнер / студия на Craftum, делает блоки для себя и клиентов.
2. **Потребитель** — другой пользователь Craftum, ставит расширение, тянет блоки из каталога.

Позже — **маркетплейс**: автор продаёт блок или подписку на набор.

## Метрика «контур закрыт»

- [x] Каталог на сервере, расширение видит N блоков.
- [x] Snapshot (`text-012222`) вставляется на канву test site 954965.
- [x] Блок редактируется штатными инструментами Craftum.
- [ ] Стабильность >95% вставок без перезагрузки.
- [ ] 10+ авторов с опубликованными блоками.
- [ ] Монетизация (хотя бы заглушка оплаты).

## Связь с Craft (мигратор)

Craft снимает **опубликованный HTML** сайта с Kraftum. Блоки Craftum Blocks живут в **редакторе** Craftum — это разные слои.

Плюс: snapshot-блоки используют те же `n-uuid`, `data-type`, `cli-block` — при миграции Page Model их проще распознать.
