# Workflow админа · сборка блоков

## Одна страница — много блоков (рекомендуется)

На test site **954965** заведите **одну мастерскую-страницу** (например «Blocks workshop»). На ней собираете **сколько угодно секций** — каждая секция = будущий блок каталога.

Страницы Craftum **не привязаны** к категориям каталога. Категории задаёте вручную при публикации и в админке.

### Правка дизайна элементов

**В нашей админке** (`/admin/craftum-blocks`) правятся только карточка каталога: название, описание, категория, превью, featured. Вёрстку и стили секции там не меняют.

**В Craftum** после вставки блока из «Мои блоки»:

1. Клик по **тексту, кнопке, картинке** на канве.
2. Справа откроется штатная панель Craftum: **Контент** / **Дизайн** (цвет, отступы, шрифт, фон…).
3. Это работает, потому что в snapshot остаются узлы `data-type` (text, button, image…).

Если блок на канве **пустой** — панель Craftum не к чему привязаться. Чаще всего причина: истекла сессия (401 в консоли) или битый snapshot при публикации. Тогда: перелогин на craftum.com → F5 → republish с тем же id.

Обновить каталог после правок в Craftum: **↑ В каталог** с **тем же id** (republish).

### Цикл

1. Открыть workshop-страницу в Craftum.
2. Добавить/править секции (дизайн-блоки с нуля).
3. **Сохранить** страницу.
4. **↑ В каталог** → в выпадающем списке выбрать **нужную секцию** с канвы.
5. Указать **уникальный id**, название, **категорию** (Обложки, Формы…), описание.
6. В админке `/admin/craftum-blocks` — превью (Ctrl+V), featured, правка текста карточки.

**Важно:** превью в админке — только картинка карточки. Содержимое блока (тексты, картинки на канве) берётся из **snapshot при публикации**. Смена превью не меняет то, что вставится в Craftum. При публикации в списке «Блок на странице» смотрите **#1, #2…** (сверху вниз) и текст секции.

### Правка и баги

| Задача | Действие |
|--------|----------|
| Текст карточки, категория, превью | Админка → Изменить |
| Вёрстка, анимации, содержимое | Craftum → правка секции → **тот же id** → ↑ В каталог |
| Новая версия, старую оставить | Новый id или Дублировать в админке |
| Убрать из каталога | Админка → Удалить (страницу Craftum можно не трогать) |

### Republish (тот же id)

Повторная публикация с тем же **id** = **обновление** snapshot в каталоге. Пользователи увидят новую версию при следующей вставке.

### Подсказки на workshop-странице

- Давайте секциям понятные **title** в Craftum — в форме публикации проще выбрать блок.
- Можно держать черновики внизу страницы и публиковать по одному.
- Удаление секции на workshop **не удаляет** блок из каталога — только вручную в админке.

### Что не нужно

- Отдельная страница Craftum на каждый блок.
- Синхронизация «удалили страницу → удалили каталог» — каталог живёт отдельно.
