# Roadmap · Craftum Blocks

План от текущего MVP до продакшена и монетизации. Обновлять по мере закрытия фаз.

---

## Фаза 0 · Контур (✅ сентябрь 2026)

**Цель:** доказать замкнутый цикл author → catalog → insert.

| Done | Item |
|------|------|
| ✅ | Расширение MV3, панель «Мои блоки» |
| ✅ | API каталог + publish + admin UI |
| ✅ | Snapshot insert через page-world + WebSocket |
| ✅ | Featured, 8 блоков в prod catalog |
| ✅ | Документация `docs/craftum-blocks/` |

**Exit:** пользователь без помощи публикует и вставляет свой text-блок.

---

## Фаза 1 · Стабильность (2–3 нед) — в работе

**Цель:** не ломаться на типовых сценариях Craftum.

| # | Задача | Статус |
|---|--------|--------|
| 1 | Retry + понятные ошибки (socket timeout, сессия) | ✅ 0.3.5 |
| 2 | Автотест: `npm run test:craftum-blocks:e2e` (headless inject) | ✅ |
| 3 | E2E с расширением: `npm run test:craftum-blocks:e2e:extension` | ✅ скрипт |
| 4 | Закрытие библиотеки / blank=true | ✅ 0.3.4+ |
| 5 | Кэш каталога: инвалидация после publish | частично |
| 6 | Превью блока в панели | 🔜 |

**Метрики:** >95% успешных вставок snapshot в тестах; 0 регрессий cover.

**Exit:** 3–5 внешних тестеров на Craftum без инструкций «перезагрузи 5 раз».

---

## Фаза 2 · Авторский UX (3–4 недели)

**Цель:** автор не думает про JSON и ключи.

| # | Задача |
|---|--------|
| 1 | Онбординг в расширении: ключ → первый publish → первая вставка |
| 2 | Выбор блока на странице по превью (не только dropdown) |
| 3 | Валидация snapshot перед publish (обязательные slug, content tree) |
| 4 | Версионирование блока (`id@version` или semver в каталоге) |
| 5 | «Мои блоки» vs «Каталог сообщества» — фильтр featured / author |
| 6 | Landing `/craftum-blocks` — актуальный copy + видео 30 сек |

**Exit:** новый автор проходит путь за <10 мин без поддержки.

---

## Фаза 3 · Продакшен расширения (4–6 недель)

**Цель:** не «ZIP для друзей», а нормальный канал дистрибуции.

| # | Задача |
|---|--------|
| 1 | Chrome Web Store listing (политика, скрины, privacy policy) |
| 2 | Edge / Яндекс.Браузер (тот же CRX/ZIP) |
| 3 | Автообновление версии с сервера (optional version check) |
| 4 | Sentry / лог ошибок вставки (без PII) |
| 5 | Rate limit + auth на publish API |
| 6 | Бэкап `catalog.json` + audit log publish/delete |

**Инфра:** уже на `craft.nordic-builder.ru` (PM2 :3040). Отдельный микросервис не нужен до 10k блоков.

**Exit:** CWS approved, установка в 1 клик, мониторинг ошибок.

---

## Фаза 4 · Монетизация (после стабильности)
