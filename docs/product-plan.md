# Product plan · Craft Migration Service

Аудитория: пользователи Craftum community — уход с подписки на конструктор, сайт на своём домене и хостинге.

## Модель продукта

**Migration-as-a-service + deployable admin**, не SaaS-конструктор.

```
Реклама → demo import (1 page, free) → preview → оплата → export.zip + admin → клиент на Beget/Timeweb/VPS
```

## Воронка

| Шаг | Действие | Цена |
|-----|----------|------|
| 1 | Вставить URL Craftum | бесплатно |
| 2 | Импорт 1 страницы + preview | бесплатно |
| 3 | CTA: «На свой хостинг с админкой» | Basic / Pro |
| 4 | Оплата | разово |
| 5 | Получить zip + login/password + README | включено |
| 6 | Деплой (сам или за доп. плату) | опционально |

**Техподдержка не входит в базовую цену** — отдельно по договорённости.

## Что получает клиент после оплаты

```
export.zip
├── site/              # HTML + assets (патченный)
├── data/content.json  # редактируемые данные
├── admin/             # WP-style панель, 1 владелец
├── api/               # form-submit, publish
└── README-deploy.md   # Beget / Timeweb / VPS
```

## Формы

- **MVP:** email only
- **Фундамент:** модель под Google Sheets + Telegram (включить позже)
- **Стратегия:** сохранить Craftum-верстку, перехватить submit (ADR-0010)
- Поля извлекаются **динамически из HTML**

## HTML-блоки и AI

- Владелец вставляет секции HTML + `<style>` + `<script>`
- AI (OpenAI): prompt → HTML + style tag → preview → вставка в slot
- API key хранится на сервере клиента, не в браузере

## Хостинг клиента

Целевой: Beget, Timeweb, VPS с Node.js.  
Требование: возможность запустить Node-приложение (admin + api + publish).

## Монетизация

1. **Разовая миграция** — основной доход
2. **Установка под ключ** — доп. услуга
3. **Care / поддержка** — опционально, отдельно (не в базе)
