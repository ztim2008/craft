# Как снять HTML и Network (для новичка)

## Главное правило

**Редактор Craftum** и **опубликованный сайт** (`fy4299.craftum.io`) — это разные вещи.

Пока не нажали **«Опубликовать»**, на живом сайте остаётся **старая** версия страницы.

---

## Почему «пустой» блок в коде всё ещё с текстом

Типичные причины:

1. **Не опубликовали** после удаления элементов.
2. **Кэш браузера** — открыли старую страницу (Ctrl+Shift+R / жёсткое обновление).
3. **Cover-пресет** — штатный дизайн-блок «обложка» при создании **уже содержит** заголовок, кнопку и картинку (демо-контент). Удаление в редакторе ≠ пустой HTML на сайте, пока это не сохранено и не опубликовано.
4. Скопировали **тот же** блок: `id="n-70774af9-17c8-4d1a-9b7b-b4638ea390b9"` — если id не менялся, это та же секция, что и в «заполненном» снимке.

---

## Как правильно снять HTML после правок

1. В **редакторе** сделайте изменения (удалите текст, кнопку и т.д.).
2. Нажмите **Опубликовать** (дождитесь «Готово»).
3. Откройте **https://fy4299.craftum.io** в новой вкладке.
4. **Ctrl+Shift+R** (жёсткое обновление).
5. ПКМ → **Просмотр кода страницы** (View Page Source), не «Просмотреть код» одного элемента.
6. Найдите `<section` с `class="cli-block"` и скопируйте эту секцию.

Если после публикации в коде **всё ещё** есть «Все инструменты для уникального дизайна» — значит элементы в редакторе не удалились из модели, а только скрылись визуально. Попробуйте выделить элемент → Delete / корзина в панели Craftum.

## Что нам нужно для расширения (приоритет)

| # | Что | Зачем |
|---|-----|--------|
| 1 | URL из адресной строки **редактора** | куда вешать расширение — **готово:** `craftum.com/app/site/954959/page/1496862` |
| 2 | Network при «+» → **новый** дизайн-блок | API вставки |
| 3 | Заполненный HTML (уже есть) | структура preset |
| 4 | Пустой HTML | желательно, но не блокер |

**Заполненного HTML уже достаточно**, чтобы начать шаблон (`presetId: ab8a097d-…`).

## Network за 5 шагов

1. Откройте **редактор** страницы (не опубликованный сайт).
2. **F12** → вкладка **Network** (Сеть).
3. Фильтр: **Fetch/XHR**.
4. Нажмите **«+»** между секциями → выберите **Дизайн-блок**.
5. В списке появятся запросы — кликните на новый **POST** (часто `api`, `blocks`, `page` в URL).

Скопируйте:
- **Request URL**
- **Request Payload** (тело запроса)

**Не присылайте** заголовки `Cookie`, `Authorization`, токены.

Можно: ПКМ по запросу → **Copy** → **Copy as cURL**, потом вырезать только URL и `--data-raw '...'`.

---

## Быстрая проверка «опубликовалось ли»

В редакторе измените заголовок на уникальное слово, например `ТЕСТ12345`, опубликуйте, обновите сайт и **Ctrl+F** по `ТЕСТ12345` в коде страницы. Если нет — публикация не дошла или смотрите не ту страницу.
