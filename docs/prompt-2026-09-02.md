## Главные правила (не нарушать)

1. Snapshot вставляется только из **`page-world.js`** (WebSocket `create_block`), не REST POST.
2. **Превью в админке ≠ содержимое блока** — только snapshot при publish.
3. Перед publish: **сохранить страницу Craftum**, обновить список секций, проверить плашку.
4. После обновления расширения — **F5** на вкладке Craftum.
5. Playwright в проде расширения — только разведка/e2e, не Profi.
6. Не коммитить `.env`, `storage/`, секреты publish key.
7. После правок расширения: `npm run build:extension` → ZIP в `public/downloads/`.
8. **Не** привязывать категории к страницам Craftum (отменено 01.09).
9. Редактирование вёрстки — в Craftum после вставки; republish с тем же id обновляет каталог.
