Craftum Blocks — установка (тестовая версия)
==========================================

WINDOWS (рекомендуется)
  1. Распакуйте этот архив в любую папку
  2. Запустите INSTALL.bat (двойной клик)
     или «Установить Craftum Blocks.bat»
  3. Следуйте окну подсказки
  4. В браузере: Режим разработчика → Загрузить распакованное
     → вставьте путь из буфера (Ctrl+V)

macOS / Linux
  1. Распакуйте архив
  2. В терминале: chmod +x install.sh && ./install.sh

Проверка
  Откройте craftum.com → редактор страницы
  Справа внизу: кнопка «Мои блоки»

Сайт: https://craft.nordic-builder.ru/craftum-blocks
