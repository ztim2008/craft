# Craftum Blocks Extension · MVP

## Установочный файл

**Скачать:** https://craft.nordic-builder.ru/craftum-blocks

Прямая ссылка на ZIP: https://craft.nordic-builder.ru/downloads/craftum-blocks-mvp.zip

Подробная инструкция: [INSTALL.md](INSTALL.md)

### Быстро

1. Скачайте ZIP → **распакуйте** в папку.
2. `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное**.
3. Укажите распакованную папку (где лежит `manifest.json`).

## Пересборка

```bash
npm run build:extension
```

## Проверка в редакторе

Тест-сайт: `https://craftum.com/app/site/954965/...` (не трогать site `954959`).

Кнопка **«Мои блоки»** справа внизу → **Добавить**.
